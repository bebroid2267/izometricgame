3D Игра с изометрическим видом сверху
URP Mobile Ready + WebGL. 
Геймплей заключается в управлении персонажем (путем клика на нужную точку на экране) для сбора ресурсов из зданий. 
Свободное перемещение камеры. 
Система накопления - выдачи ресурсов с каждого здания, Pop Up. 
Сохранение звука
